# Simulador de Comissao com While

Estudo em Python para simular o calculo de uma comissao sobre o valor de um produto anunciado.

## Visao geral

Este repositorio registra um exercicio introdutorio de programacao em Python. O script usa entrada de dados pelo terminal, calculo percentual e estrutura `while` com interrupcao por `break`.

## Problema resolvido

O exercicio demonstra como calcular o valor final de um produto quando uma plataforma aplica uma taxa percentual sobre o preco informado pelo usuario.

## Principais funcionalidades

- Entrada do nome do produto.
- Entrada do valor do produto.
- Validacao simples de valor minimo.
- Calculo de comissao percentual.
- Exibicao do valor final no terminal.
- Uso de `while` e `break`.

## Como funciona

O usuario informa o produto e o valor. Quando o valor atende a condicao definida no script, o programa soma a taxa ao preco original e mostra o resultado final.

## Tecnologias utilizadas

- Python
- Linha de comando
- Replit identificado por arquivos do repositorio
- Poetry identificado por `pyproject.toml`

## Arquitetura

Projeto simples com um unico script principal.

## Estrutura do projeto

- `main.py`: script com a simulacao de cadastro e calculo de comissao.
- `pyproject.toml`: configuracao Python/Poetry.
- `poetry.lock`: lockfile de dependencias.
- `replit.nix` e `.replit`: arquivos de ambiente Replit.
- `venv/`: ambiente virtual versionado no repositorio.

## Status

Projeto de estudo. Nao representa uma aplicacao de producao e deve ser apresentado apenas como registro de aprendizagem em Python.

## Limitacoes conhecidas

- Fluxo executado apenas pelo terminal.
- Nao possui testes automatizados.
- O ambiente virtual esta versionado no repositorio, o que nao e recomendado para projetos futuros.
